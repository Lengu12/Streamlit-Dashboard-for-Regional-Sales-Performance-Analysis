# Regional Sales Performance Dashboard

This project is a Streamlit-based analytics dashboard designed to support a Regional Sales Manager in making data-driven decisions.

## Features
- KPI overview (Sales, Profit, Orders)
- Category performance analysis
- Sales trends over time
- Regional sales distribution
- Top-performing products
- Key insights and recommendations

## Tools Used
- Python
- Streamlit
- Pandas
- Plotly
- PostgreSQL (local setup)


## Note
This version connects to a local PostgreSQL database (`localhost`). To run the app, ensure the database is set up locally or modify the data source accordingly.

## Run Locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
